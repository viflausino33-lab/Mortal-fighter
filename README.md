# Mortal Fighter

Jogo de luta em HTML5 Canvas inspirado nos grandes torneios de artes marciais e dimensões paralelas.

## Objetivo

Criar um jogo de luta 2D completo com:

- Personagens originais
- Sistema de combos
- Golpes especiais
- IA avançada
- Modo Arcade
- Ranking
- Multiplayer futuro

## Tecnologias

- HTML5 Canvas
- JavaScript ES6
- GitHub
- Vercel
